프롬프트: 
넌 웹개발 10년차 전문가야.
이번에 시안처럼 스플래쉬 화면을 모바일 전용으로 구현해줘.
기술은 html, css, javascript만을 사용해서 구현해줘.
3초동안 로딩 막대와 퍼센트가 실행되도록 구현하고, 자동으로 네이버로 하이퍼링크를 연결해줘.
이미지와 로고는 내가 임의로 첨부할 수 있도록 구현해줘.




아주 좋아. 코드를 그대로 유지한 채, 이번에는 'hero'에 반복, 좌우 드래그가 가능한 swiper slide를 구현해줘.
hero에 들어갈 슬라이드 이미지는 총 5개야. 이미지는 내가 임의로 첨부할 수 있도록 해줘.


'hero'에 좌우 드래그가 가능하지만 드래그를 하면 해당 슬라이드가 전환 되어야해. 그리고 자동으로 슬라이드 될때 마지막 슬라이드에서 처음 슬라이드로 이동하지 않게 반복형으로 구현해줘.





너는 앱 개발 10년차 전문가야.
이번에 첨부한 시안처럼 제주도 자전거길 커뮤니티 서비스를 구현하려고 해.
기술은 html, css, javascript 만을 반드시 사용하여 구현해야해.
데이터 공공 데이터의 api 서버 주소는 'https://apis.data.go.kr/B551011/GoCamping' 이야.
api 키는 따로 코드에서 수정해서 내가 넣을게.
다음과 같은 기능으로 코드를 구현해줘.

- 커뮤니티 화면에서 'view active' 버튼을 누르면 2번째 시안 페이지로 이동하도록 구현해줘.
-2번째 시안 페이지의 상단 이미지 칸에 임의의 제주도 자전거길 로드맵을 보여주도록 구현해줘.
- 시안 처럼 정교하게 ui를 다듬어주고
- 지도 연동(카카오맵)
